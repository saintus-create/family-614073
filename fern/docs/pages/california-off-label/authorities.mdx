## Workers' compensation branch

If the proposed prescription concerns a work-related injury or illness, activate the MTUS pathway. The MTUS Drug Formulary defines off-label use to include a condition, dosage, or administration method not listed in FDA-approved labeling. Title 8 CCR § 9792.27.5 separately governs off-label use and prospective review. 

[MTUS overview](https://www.dir.ca.gov/dwc/mtus/mtus.html)

[§ 9792.27.5 — Off-Label Use](https://www.dir.ca.gov/t8/9792_27_5.html)

## Coverage is a separate layer

California health-plan coverage rules are not the same thing as authority to prescribe. The existing [coverage authorization pathway](/coverage) should be used when the issue is payer coverage or authorization.

## Registry fields

Every authority record should ultimately expose:

- Citation
- Authority type
- Primary-source URL
- Effective date
- Last verified date
- Applicability conditions
- Mandatory / permissive / advisory / evidentiary status
- Triggering facts
- Provider action
- Related authorities
- Related evidence
- Related forms or authorization pathways
